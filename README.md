<br>
<h1 align="left">Как поднять поднять этот проект?</h1>
<p align="left">Выполните эти шаги и всё будет хорошо(наверно...?)</p>
<h2>В Git Bash склонируйте репозиторий:</h2>
<code>
    git clone -SSH-ссылка на репозиторий-
</code>

<h2>Перейдите в папку:</h2>
<code>
    cd up09-lab5-Timokhina/lab1/lab1
</code>

<h2>Установим виртуальную среду:</h2>
    <code>
        python -m venv venv
    </code>

<h2>Теперь активируем виртуальную среду:</h2>
    <code>
        source venv/Scripts/activate
    </code>

<h2>Установка зависимостей:</h2>
    <code>
        pip install -r requirements.txt
    </code>

<h2>Поднимите сервер:</h2>
    <code>
        py manage.py runserver
    </code>
